# Retail Sales Analytics

## Project Overview

Retail Sales Analytics is a data analysis project focused on exploring retail transaction data to identify sales patterns, customer purchasing behaviour, product performance, and regional business trends.

The project aims to transform raw retail data into meaningful insights that support data-driven business decisions.

## Project Objectives

- Analyse overall retail sales performance.
- Identify top-performing product categories and sub-categories.
- Understand customer segments and purchasing behaviour.
- Evaluate regional sales performance.
- Explore sales trends over time.
- Generate actionable business insights.

## Dataset Description

The dataset contains retail order and transaction information, including:

- Order ID and Order Date
- Customer ID and Customer Name
- Customer Segment
- Country, City, State and Region
- Product Category and Sub-Category
- Product Name
- Sales
- Shipping Mode and Shipping Date
